# Code of Conduct

## Our pledge

We want this project to be a welcoming, respectful place for everyone. Harassment, discrimination, personal attacks, and sharing another person's private activity data are not acceptable.

## Expected behavior

- Be constructive and assume good intent.
- Keep examples and bug reports free of personal activity data.
- Respect different workflows, operating systems, and privacy preferences.
- Focus feedback on ideas and implementation, not people.

## Reporting

For security or privacy concerns, follow [SECURITY.md](SECURITY.md). For other conduct concerns, open a private report through the repository owner's GitHub profile rather than posting sensitive details publicly.
