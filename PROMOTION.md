# Launch Kit

## One-line description

Computer Usage Summary is a local-first Codex plugin that turns ActivityWatch
records into privacy-preserving daily and weekly app-usage reports.

## GitHub / Community Post

I open-sourced **Computer Usage Summary**, a cross-platform Codex plugin for
answering a simple question: *where did my computer time go?*

It reads only local ActivityWatch data and produces app time, AFK time,
foreground sessions, and a sanitized timeline. URLs are removed, spreadsheet
formula cells are escaped, and no browser extension, cloud sync, or telemetry
is required.

It supports macOS, Windows, and Linux, plus Markdown, TSV, CSV, and JSON
exports. Feedback and privacy-focused contributions are welcome.

Repository: https://github.com/liuyewang/computer-usage-summary-skill
