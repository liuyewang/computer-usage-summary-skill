# Support

Use the project's [GitHub Issues](https://github.com/liuyewang/computer-usage-summary-skill/issues/new/choose)
for installation, compatibility, and reporting questions.

Before opening an issue, remove all ActivityWatch exports, window titles, URLs,
account names, local paths, screenshots with private content, and access tokens.
For suspected security or privacy vulnerabilities, follow
[SECURITY.md](SECURITY.md) instead of opening a public issue.

The project is maintained on a best-effort basis. It does not provide managed
hosting, account support, cloud synchronization, or data recovery.
