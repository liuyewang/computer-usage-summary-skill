# Validation Scorecard

This public scorecard tracks whether the project should invest in a paid local
Pro trial. It deliberately excludes usage telemetry and never asks people to
share ActivityWatch events, window titles, URLs, account names, or local paths.

## Target users

- Independent consultants who prepare client timesheets.
- Freelancers who need project and billable-time reviews.
- Creators and developers who want a private weekly work review.

## Public signals

Record these every two weeks in the GitHub release or discussion update:

| Signal | Source | Current | Why it matters |
| --- | --- | ---: | --- |
| GitHub stars | Repository | Not measured yet | Initial discovery |
| Forks | Repository | Not measured yet | Reuse and trust |
| Install or report feedback | GitHub Discussions | Not measured yet | Activated use |
| Design-partner conversations completed | Maintainer notes | 0 | Problem evidence |
| Users who generate a weekly report repeatedly | Voluntary feedback | 0 | Retention evidence |
| Users who explicitly say they would pay | Voluntary feedback | 0 | Pricing evidence |

## Interview prompts

Ask for high-level workflow descriptions only:

1. When do you need to reconstruct where your work time went?
2. Which report would you open weekly: client timesheet, weekly review, or app trend?
3. What must stay local for you to trust this tool?
4. What would make an advanced local report worth paying for?

## Pro decision gate

Do not add accounts, cloud sync, payment processing, advertising, or team
monitoring during validation. Consider a small Pro trial only after all of the
following are true:

- At least 30 activated users provide installation or report feedback.
- At least 10 users report generating weekly reports repeatedly.
- At least 6 users explicitly state a willingness to pay for a specific
  advanced local report.

Candidate Pro features are advanced local templates, project attribution,
billable client reports, branded PDF export, long-term trends, and offline local
AI review. Price and launch date remain undecided until this evidence exists.

## 中文说明

这份面板只记录公开、低敏感度的产品验证信号，不采集窗口标题、网址、应用明细或活动记录。达到“30 名激活反馈用户、10 名持续周报用户、6 名明确愿意付费用户”前，不启动付费版设计，也不引入账号、云同步或支付。
